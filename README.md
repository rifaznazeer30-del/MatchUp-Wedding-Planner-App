# Matchup – Wedding Planner App

Matchup is a mobile wedding planning application designed to help couples organise and manage their wedding planning in one place.

## 🎨 UI/UX Design

The UI/UX design for Matchup was created using Figma.

**Figma Design:**
[View Matchup UI/UX Design](https://www.figma.com/design/NDJ5euIklQbCA2QEHUxqVg/Wedding-Planner-App?node-id=0-1&t=A97invAjGT4DNi67-1)

## ✨ Main Features

* AI Wedding Assistant
* Budget Rescue Mode
* Smart Guest Seat Optimizer
* Wedding Task Management
* Expense Tracking
* Budget Management
